# homebrew-lore

Homebrew tap for [lore](https://github.com/apisandipas/lore): typed project notes linked to the code they govern.

```bash
brew install apisandipas/lore/lore
```

This installs lore's standalone binary for macOS or Linux, and ripgrep, which lore needs. Upgrade with `brew upgrade lore`.

`Formula/lore.rb` is generated from each release by `scripts/homebrew-formula.sh` in the lore repo; change that script, not the formula.
